# 📝 Update Log / Release Notes

## 🚀 変更点
- **SCPによるリモートデプロイへの移行**: ビルド時にJARファイルをローカルフォルダへ直接コピーする方式から、**SCP（Secure Copy）** を利用してリモートサーバーへ自動転送する方式に変更しました。

---

## ⚙️ 必要な設定の追加・更新
プロジェクトのルートディレクトリに配置する `server-config.properties` に、以下の項目を設定してください。

```properties
# リモートサーバーのSSH接続・デプロイ設定
serverUser=
deployPath=
privateKeyPath=
serverIp=
serverPort=25585
```
